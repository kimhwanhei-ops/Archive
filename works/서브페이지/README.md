# Dessert Lab 서브페이지 — 시안 일치형 웹 파일

## 실행

1. 이 폴더를 압축 해제합니다.
2. VS Code에서 **이 폴더 전체**를 엽니다.
3. 루트 `index.html`을 **Live Server**로 실행합니다. 또는 `index.html`을 브라우저에서 직접 열어도 됩니다.
4. 다른 팀 코드에 덮어쓰지 말고, 별도 폴더에서 먼저 확인합니다.

## 파일 구조

- `index.html`: 페이지 구조, 섹션 및 클릭 영역
- `css/style.css`: 정확한 이미지 비율, 반응형 크기, 모달 스타일
- `js/jquery-3.6.1.min.js`: jQuery 3.6.1 오프라인 포함
- `js/script.js`: 카드 모달, 페이지 번호 알림, 섹션 스크롤, 키보드 조작
- `assets/sections/`: 원본 시안을 **가로로 정확히 7등분한 섹션 이미지**. 위아래를 다시 합치면 원본과 동일합니다.
- `assets/individual/`: 요청하신 카드·지도·케이크 등 개별 이미지 크롭 파일

## 원본 보존 및 한계 (중요)

원본 시안(2240×5000 이미지)에서 **자르기만 했습니다**. 기존 사진, 문구, 색상, 여백, 로고를 다시 그리거나 수정하지 않았습니다. 따라서 최초 렌더링은 시안과 같은 구성입니다.

**단, 섹션의 사진과 문자들은 원본 목업에 합성되어 있습니다.** 사진의 겹쳐 가려진 부분이나 텍스트 없는 배경을 원본 그대로 추출할 수 없으므로, 그 부분을 가짜로 생성하거나 복원하지 않았습니다.
현재 HTML은 화면 재현 정확도를 위해 섹션 이미지를 사용하고, 투명한 HTML 클릭 영역을 위에 배치한 방식입니다. 그러므로 모든 카피를 개별 HTML 텍스트로 수정할 수 있는 '완전 컴포넌트화' 구조는 아닙니다. 원본 사진/레이어 소스를 제공해 주시면 추후 컴포넌트화가 가능합니다.

- 카드 네 개: 정확히 해당 화면에 보인 카드만 개별 크롭, 클릭 시 같은 카드의 큰 이미지가 열립니다.
- 'Layer Cake': 가운데 보이는 카드만 개별 크롭 및 확대 기능을 제공합니다.
- 원본에 2~4페이지의 실제 사진이 없기 때문에, 임의의 사진을 채우지 않았습니다. 해당 버튼을 누르면 안내만 표시합니다.
- 좌·우 겹친 갤러리 사진은 뒤에 가려진 부분이 포함되지 않으며, `visible`로 명명했습니다.
- 원본 시안은 세로가 긴 래스터 이미지이므로 모바일에서 텍스트 크기는 화면 크기에 비례하여 작아집니다. HTML 레이아웃을 재설계하지 않아 시안 외양은 바뀌지 않습니다.

## 팀 프로젝트 통합 시

현재 팀 루트 `index.html`, `style.css` 등을 **절대 덮어쓰지 마세요.** 이 프로젝트 전체를 새 하위 폴더(예: `dessert-subpage/`)로 옮긴 뒤 팀 메인에서 `dessert-subpage/index.html`로 연결하면 충돌 위험이 낮습니다.
